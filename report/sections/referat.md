# РЕФЕРАТ

Пояснительная записка 107 с, 45 рисунков, 8 таблиц, 17 источников, 2 приложения.

Графическая часть: 26 слайдов презентации PowerPoint.

ЛАБИРИНТ, ТОЛСТОСТЕННЫЙ ЛАБИРИНТ, ГЕНЕРАЦИЯ ЛАБИРИНТА, ПОИСК ПУТИ, АЛГОРИТМ ПРИМА, ВОЛНОВОЙ АЛГОРИТМ, ВИЗУАЛИЗАЦИЯ, ПРОХОЖДЕНИЕ.

Во время курсового проектирования разработаны алгоритмы и соответствующая им программа, предназначенная для генерации структуры лабиринта и нахождения выхода из него, с помощью которой игрок сможет проходить лабиринты, созданные администратором, вручную или автоматически, а также визуализировать их в выбранной теме оформления. В системе имеется возможность сохранения лабиринтов в базе данных с целью последующего их прохождения.

Программа написана на языке TypeScript в среде Visual Studio Code и функционирует под управлением операционной системы Windows 10 и выше. Доступ к данным осуществляется с помощью СУБД PostgreSQL 16.
