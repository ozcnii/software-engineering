## 2.7 Выбор и обоснование комплекса программных средств

Для реализации системы «Лабиринт» выбран комплекс программных средств, обеспечивающий разработку клиентской и серверной частей web-приложения, хранение данных, построение UML-диаграмм и сопровождение исходного кода. При выборе учитывались кроссплатформенность, поддержка типизации, удобство разработки интерфейса, возможность построения REST API и работа с реляционной базой данных.

### 2.7.1 Выбор языка программирования

В качестве основного языка программирования выбран TypeScript. TypeScript является расширением JavaScript и добавляет статическую типизацию, интерфейсы, перечисления и проверку типов на этапе компиляции. Это снижает количество ошибок при разработке и упрощает сопровождение приложения.

Для системы «Лабиринт» TypeScript удобен тем, что применяется во всех основных частях проекта: в клиентской части на React, в серверной части на NestJS и в общем пакете типов. За счет этого структуры данных, передаваемые между клиентом и сервером, описываются единообразно. Например, типы пользователя, лабиринта, сетки, алгоритмов генерации и алгоритмов решения используются как общие контракты.

Исполнение серверной части выполняется в среде Node.js версии 22.18.0. Node.js обеспечивает запуск TypeScript/JavaScript-приложений вне браузера и хорошо подходит для построения серверных приложений с REST API.

### 2.7.2 Выбор операционной системы

В качестве операционной системы рабочего места разработчика используется macOS 26.4.1. macOS предоставляет Unix-подобную среду, удобную для разработки web-приложений, работы с терминалом, Git, Node.js и Docker. Операционная система поддерживает необходимые инструменты разработки и позволяет запускать клиентскую часть, серверную часть и контейнер с базой данных локально.

Использование macOS также удобно для работы с Visual Studio Code, пакетным менеджером npm, PlantUML и средствами командной строки. Это позволяет выполнять разработку, сборку, проверку типов, генерацию диаграмм и запуск приложения в одной среде.

### 2.7.3 Выбор среды программирования

В качестве среды программирования выбран Visual Studio Code версии 1.120.0. Данная среда поддерживает TypeScript, JavaScript, React, Node.js, работу с терминалом, Git и расширениями для форматирования и анализа кода.

Visual Studio Code выбран из-за удобной навигации по проекту, встроенного терминала, подсветки синтаксиса, автодополнения и поддержки TypeScript. Для проекта, состоящего из frontend, backend и shared-пакета, это позволяет быстро переходить между клиентскими компонентами, серверными модулями, DTO и общими типами.

### 2.7.4 Выбор системы управления базами данных

В качестве системы управления базами данных выбрана PostgreSQL 16. PostgreSQL является реляционной СУБД и поддерживает первичные и внешние ключи, индексы, перечисления и тип JSON. Эти возможности соответствуют структуре данных системы «Лабиринт».

В базе данных хранятся пользователи и созданные лабиринты. Сетка лабиринта сохраняется в JSON-поле, так как она представляет собой двумерную структуру клеток. Для доступа к базе данных используется Prisma ORM, который связывает TypeScript-код серверной части со схемой PostgreSQL и упрощает выполнение операций чтения и записи.

### 2.7.5 Выбор вспомогательных средств разработки

Для клиентской части выбран React 19.1.1 и сборщик Vite. React используется для построения экранов авторизации, администратора и игрока, а Vite обеспечивает быстрый запуск и сборку клиентского приложения.

Для серверной части выбран NestJS 11. Данный фреймворк позволяет строить модульную серверную часть, разделять ответственность между модулями авторизации, пользователей и лабиринтов, а также описывать REST API.

Для управления зависимостями используется npm 10.9.3. Для локального запуска базы данных применяется Docker Compose с образом PostgreSQL 16. Для построения UML-диаграмм используется PlantUML. Для контроля версий используется Git и удаленный репозиторий GitHub.
