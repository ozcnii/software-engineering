## 3.2.1 Диаграмма компонентов

Диаграмма компонентов описывает особенности физической реализации приложения, определяет архитектуру приложения и устанавливает зависимость между компонентами, в роли которых выступает исполняемый код. Диаграмма компонентов отображает общие зависимости между компонентами. Основными графическими элементами диаграммы являются компоненты, интерфейсы и зависимости между ними [?].

Диаграмма компонентов системы «Лабиринт» отображена на рисунке N. Компоненты, входящие в диаграмму, представлены в таблице N.

![Рисунок N – Диаграмма компонентов системы](../../diagrams/components/component-diagram.png)

Рисунок N – Диаграмма компонентов системы

| Название компонента | Назначение компонента |
| --- | --- |
| React/Vite frontend | Пользовательский интерфейс приложения |
| features/auth | Формы входа и регистрации |
| features/admin | Интерфейс администратора для просмотра, создания и удаления лабиринтов |
| features/player | Интерфейс игрока для выбора, ручного прохождения и автоматического решения лабиринтов |
| shared/api | API-клиент приложения |
| shared/types | Общие типы данных приложения |
| NestJS backend API | Серверная часть приложения |
| AuthModule | Аутентификация, регистрация, выход и получение текущего пользователя |
| UsersModule | Работа с пользователями |
| LabyrinthsModule | Операции со списком, созданием, удалением, деталями и решением лабиринтов |
| GenerationModule | Генерация лабиринтов алгоритмами Прима и Краскала |
| SolvingModule | Поиск пути в лабиринте алгоритмами BFS и DFS |
| Prisma Client | Программный слой доступа backend к PostgreSQL |
| PostgreSQL | Хранение данных о пользователях и лабиринтах |
