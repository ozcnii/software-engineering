# Шаблон презентации защиты курсового проекта

Шаблон собран **строго по 7 эталонным презентациям** из `asd/` (группы 6301–6303).
Структура у всех одинаковая; ниже — общий каркас. Заполняйте плейсхолдеры `‹…›`
своим текстом и картинками. **Лишних слайдов не добавлять**, порядок не менять.

Обозначения:
- **[ОБЯЗ.]** — слайд есть во всех/почти всех эталонах, нужен всегда.
- **[ЕСЛИ ЕСТЬ]** — слайд добавляется, только если в проекте есть соответствующий
  артефакт (например, физическая модель БД, алгоритм). Нет артефакта — нет слайда.
- **[×N по ролям/частям]** — слайд повторяется столько раз, сколько нужно
  (по одной диаграмме на роль / на часть), как в эталонах.

---

## Общие правила оформления (одинаково во всех эталонах)

- Заголовок раздела/слайда — сверху, одной строкой, как в списке ниже (формулировки дословные).
- В правом нижнем углу — номер слайда в формате `N / ‹всего›` (или просто `N`).
- Диаграммные слайды = **заголовок + одна крупная картинка диаграммы**, без текста.
- Текстовые слайды (описание ПО, аналоги, итоги) = заголовок + маркированные списки.
- Разделители-секции («Анализ предметной области», «Проектирование системы»,
  «Реализация системы») — отдельный слайд только с названием раздела (крупно по центру).
- Итоговый объём эталонов — **21–28 слайдов**. Ориентируйтесь на этот диапазон.
- Вместо именованных разделителей допустим слайд **«Содержание»** (оглавление из трёх
  пунктов: Анализ ПО / Проектирование / Реализация), повторяемый перед каждым разделом
  (как в эталоне «Ресторан»).
- Порядок **«Диаграмма классов»** и **«Диаграмма развёртывания»** в эталонах варьируется —
  оба относятся к разделу «Реализация».

достоинства/недостатки на слайдах аналогов.

```

| Показатель             | ‹Аналог 1› | ‹Аналог 2› | Разрабатываемая система |
|------------------------|:---------:|:---------:|:-----------------------:|
| ‹Удобство навигации›   |     -     |     +     |            +            |
| ‹Наличие поиска›       |     +     |     -     |            +            |
| ‹…›                    |     …     |     …     |            …            |
```
