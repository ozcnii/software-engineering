## Сценарий 1: «Ввести название лабиринта»

**Вариант использования:** «Ввести название лабиринта».

**Краткое описание.** Позволяет администратору ввести название создаваемого лабиринта. Включается в вариант использования «Создать лабиринт».

**Тип.** Включаемый.

**Актант.** Администратор.

**Предусловия.** Компьютер включён, вход в систему в роли администратора выполнен успешно. На экране отображена главная форма приложения. Администратор выбрал пункт меню «Создать лабиринт».

**Основной поток событий.**

1 Система выводит на экран форму создания лабиринта, шаг 1 «Параметры» (см. рисунок N). На форме отображаются: поле ввода «Название лабиринта» с подсказкой «например: Зимний лабиринт…», блок «Размеры» с числовыми полями «Ширина» и «Высота», блок «Тема оформления» с радиокнопками «Зима», «Лето», «Осень», «Весна», блок «Вход и выход» с радиокнопками «Авто (на периметре)» и «Вручную (на холсте)», блок «Алгоритм генерации» с радиокнопками «Алгоритм Прима» и «Алгоритм Краскала», кнопки «Отмена» и «Далее — Сгенерировать».

2 Администратор щёлкает левой кнопкой мыши (ЛКМ) в поле «Название лабиринта».

А1: Администратор щёлкает ЛКМ по кнопке «Отмена».

3 Система делает поле «Название лабиринта» активным, подсказка «например: Зимний лабиринт…» исчезает, курсор устанавливается в начало поля ввода.

4 Администратор вводит название лабиринта с клавиатуры.

А1: Администратор щёлкает ЛКМ по кнопке «Отмена».

5 Администратор щёлкает ЛКМ по кнопке «Далее — Сгенерировать». Система проверяет заполненность поля «Название лабиринта».

А2: Поле «Название лабиринта» оставлено пустым.

6 Система запоминает введённое название. Вариант использования завершается успешно.

**Альтернативы.**

А1: Администратор щёлкнул ЛКМ по кнопке «Отмена».

А1.1 Система закрывает форму создания лабиринта и выводит на экран список лабиринтов.

А1.2 Вариант использования завершается.

А2: Поле «Название лабиринта» оставлено пустым.

А2.1 Система открывает модальное окно с сообщением «Введите название лабиринта». На форме располагается кнопка «ОК».

А2.2 Администратор щёлкает ЛКМ по кнопке «ОК».

А2.2.1 Модальное окно с сообщением закрывается.

А2.2.2 Осуществляется переход к п. 2 основного потока событий.

**Постусловия.** При успешном завершении введённое название лабиринта сохранено в форме параметров шага 1 «Параметры».

**Неясные вопросы.** Уточнить максимально допустимую длину названия лабиринта, а также допустимые символы для ввода.

## Сценарий 2: «Изменить тему оформления»

**Вариант использования:** «Изменить тему оформления».

**Краткое описание.** Позволяет игроку изменить визуальное оформление лабиринта для текущей игровой сессии. Расширяет вариант использования «Выбрать лабиринт из списка».

**Тип.** Расширяющий.

**Актант.** Игрок.

**Предусловия.** Компьютер включён, вход в систему в роли игрока выполнен успешно. На экране отображён экран игрока (см. рисунок N). Игрок выбрал лабиринт из списка доступных. В блоке «Тема оформления» левой панели по умолчанию установлена тема, заданная администратором при создании лабиринта.

**Основной поток событий.**

1 Система выводит на экран игрока (см. рисунок N). На экране отображаются: левая панель с блоком «Выбор лабиринта», блоком «Тема оформления» с радиокнопками «Зима», «Лето», «Осень», «Весна» и подписью «изменение локально для сессии», блоком «Информация» с кнопками «О разработчике» и «О системе»; центральная область с визуализацией лабиринта и переключателем режимов «Ручной» / «Авто-решение»; правая панель со статистикой, легендой и кнопками «Сбросить» и «Выйти из уровня».

2 Игрок щёлкает левой кнопкой мыши (ЛКМ) на радиокнопку необходимой темы оформления в блоке «Тема оформления».

А1: Игрок щёлкает ЛКМ по кнопке «Выйти из уровня».

3 Система устанавливает выбранную радиокнопку активной, снимает выделение с предыдущей.

4 Система перерисовывает визуализацию лабиринта в центральной области в соответствии с выбранной темой оформления. Вариант использования завершается успешно.

**Альтернативы.**

А1: Игрок щёлкнул ЛКМ по кнопке «Выйти из уровня».

А1.1 Система закрывает текущий уровень и возвращает игрока на экран выбора лабиринта.

А1.2 Выбранная тема оформления не сохраняется.

А1.3 Вариант использования завершается.

**Постусловия.** При успешном завершении визуализация лабиринта отображается в соответствии с выбранной темой оформления. Изменение действует только в рамках текущей сессии и не сохраняется в базе данных.

**Неясные вопросы.** Уточнить, сбрасывается ли тема оформления к значению по умолчанию при повторном входе в тот же лабиринт.
